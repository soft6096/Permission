# 技术方案：权限数据初始化

## 基本信息

- 功能项：#15 权限数据初始化
- 类型：无入口（启动初始化 CommandLineRunner）
- 优先级：P1 | 依赖：—

## 第零段 功能定性

- 入口形态：**无**（无 HTTP/MQ/Job，应用启动时自动执行）→ 仅写通用章节，不写类型四段
- 业务复杂度：**中等**——多表预置数据写入，需幂等控制
- 跨功能项规则：admin 角色（`admin`）与 admin 账号的"不可删改"属性由此初始化数据奠定（用户管理/角色管理方案的 admin 保护针对编码判断）

## 通用章节

### 功能说明

应用启动时，检测权限基础数据是否已存在（按 `sys_permission.permission_code` 预置编码判断），不存在则插入预置数据，重复启动不产生重复数据（幂等）。

预置内容：

| 预置项 | 表 | 数据 |
|---|---|---|
| 目录 | sys_permission | 系统管理（code=`sys`，type=1，parent_id=0，sort=1） |
| 页面 | sys_permission | 用户管理（code=`sys:user`，type=2，parent=系统管理）、角色管理（code=`sys:role`，type=2，parent=系统管理） |
| admin 角色 | sys_role | role_code=`admin`，role_name=超级管理员 |
| admin 角色-全权限 | sys_role_permission | admin 角色关联全部权限 |
| admin 账号 | sys_user | username=`admin`，密码 BCrypt(`admin123`)，status=1（启用），force_change=1（首次登录强制改密） |
| admin 账号-角色 | sys_user_role | admin 账号关联 admin 角色 |

### 验收场景（测试用例蓝本）

| # | 场景 | 输入/前置 | 期望 |
|---|------|-----------|------|
| 1 | 首次启动初始化 | 权限表为空 | 预置数据全部插入，admin 角色拥有全部权限，admin 账号 force_change=1 |
| 2 | 重复启动幂等 | 已初始化完成 | 不产生重复权限/角色/账号数据，各表记录数不变 |
| 3 | 部分已存在 | 仅权限表已预置 | 跳过已存在的权限，补齐缺失的关联与账号 |

## 数据模型 DDL（用户侧，sys_user_role 与角色侧共用）

```sql
-- 用户表
CREATE TABLE `sys_user` (
  `id`          BIGINT      NOT NULL COMMENT '主键ID（雪花）',
  `username`    VARCHAR(50) NOT NULL COMMENT '用户名（唯一，存小写）',
  `password`    VARCHAR(100) NOT NULL COMMENT '密码（BCrypt 密文）',
  `nickname`    VARCHAR(50) NOT NULL COMMENT '姓名',
  `status`      TINYINT     NOT NULL DEFAULT 1 COMMENT '状态：0-禁用 1-启用',
  `force_change` TINYINT    NOT NULL DEFAULT 0 COMMENT '强制改密：0-否 1-是（首次登录/重置后置1）',
  `create_time` DATETIME    NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time` DATETIME    NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  `deleted`     TINYINT     NOT NULL DEFAULT 0 COMMENT '逻辑删除：0-未删 1-已删',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_username` (`username`),
  KEY `idx_user_nickname` (`nickname`)
) ENGINE = InnoDB DEFAULT CHARSET = utf8mb4 COMMENT = '用户表';

-- 用户-角色关联表
CREATE TABLE `sys_user_role` (
  `id`          BIGINT   NOT NULL COMMENT '主键ID（雪花）',
  `user_id`     BIGINT   NOT NULL COMMENT '用户ID',
  `role_id`     BIGINT   NOT NULL COMMENT '角色ID',
  `create_time` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  `deleted`     TINYINT  NOT NULL DEFAULT 0 COMMENT '逻辑删除：0-未删 1-已删',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_user_role` (`user_id`, `role_id`),
  KEY `idx_role_id` (`role_id`)
) ENGINE = InnoDB DEFAULT CHARSET = utf8mb4 COMMENT = '用户-角色关联表';
```
