## 拆解说明

- 全模块无 MQ 消费（Listener）与定时任务（Job）需求，故全部为 Controller 或"无入口"。
- #15 权限数据初始化是系统预置数据（需求 2.2：权限不做维护界面），无 HTTP 入口，为启动时自动执行的初始化逻辑。
- #16 后端接口权限校验是需求 4 的第 3 环节（安全底线），实现为横切中间件/拦截器，独立成项便于单独验收。
- #3 菜单树独立成项：登录时返回一次（#1），前端刷新页面时也需独立拉取，两个使用场景。
- #4~#9 用户管理各操作独立成项，可独立开发/测试/交付；接口内聚为 UserController（技术方案 #4~#9 合并写一份）。
- #10~#13 角色管理同理，接口内聚为 RoleController（技术方案 #10~#13 合并写一份）。
- #1、#2、#14 认证相关接口内聚为 AuthController（技术方案 #1/#2/#14 合并写一份）。
- #15、#16 无 Controller，技术方案仅使用 3.0 通用骨架章节。
