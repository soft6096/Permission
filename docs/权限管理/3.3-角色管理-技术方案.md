# 技术方案：角色管理

## 基本信息

- 功能项：#10 角色列表、#11 新增/编辑、#12 删除角色、#13 分配权限
- 类型：Controller（RoleController）
- 优先级：P1 | 依赖：#15（权限数据初始化，分配权限时权限树来自预置数据）

## 第零段 功能定性

- 入口形态：**有**，HTTP 请求
- 业务复杂度：**中**——列表单表分页；分配权限/删除为多表写（级联角色-权限、用户-角色）；admin 保护
- 跨功能项规则：admin 角色保护规则定义在**本方案**（角色侧）

## 二、数据契约 → 入参出参 JSON + 校验规则

**入参示例**：

```json
// GET /sys/role/page?roleName=管&roleCode=&pageNum=1&pageSize=10
// POST /sys/role  新增
{
  "roleName": "运营",
  "roleCode": "operator",
  "description": "日常运营角色"
}
// PUT /sys/role/2  编辑
{
  "roleName": "运营专员",
  "roleCode": "operator",
  "description": "运营角色"
}
// PUT /sys/role/2/permissions
{ "permissionIds": [1, 2, 3] }
```

**出参示例**：

```json
// 分页
{ "code": 200, "message": "操作成功", "data": { "total": 1, "records": [ { "roleId": 2, "roleName": "运营", "roleCode": "operator", "description": "日常运营角色" } ] } }
// 详情（含已分配权限）
{ "code": 200, "message": "操作成功", "data": { "roleId": 2, "roleName": "运营", "roleCode": "operator", "permissionIds": [1, 2] } }
// 权限树（目录+页面）
{ "code": 200, "message": "操作成功", "data": [
  { "permissionId": 1, "permissionName": "系统管理", "permissionCode": "sys", "parentId": 0, "type": 1, "route": null, "sort": 1, "children": [
      { "permissionId": 2, "permissionName": "用户管理", "permissionCode": "sys:user", "parentId": 1, "type": 2, "route": "/sys/user", "sort": 1, "children": [] }
  ] }
] }
// 角色编码重复
{ "code": 1004, "message": "角色编码已存在", "data": null }
// admin 保护
{ "code": 1006, "message": "超级管理员不允许该操作", "data": null }
```

**校验规则（逐字段）**：

- RoleQueryDTO.roleName：可选，模糊查询
- RoleQueryDTO.roleCode：可选，模糊查询
- RoleSaveDTO.roleName：必填，1-50 字符
- RoleSaveDTO.roleCode：必填，1-50 字符，**唯一**
- RoleSaveDTO.description：可选，0-255 字符
- RoleEditDTO 同 SaveDTO（roleCode 不允许修改，见下）
- PermissionAssignDTO.permissionIds：可空（空=清空全部权限）
- 分页参数 pageNum/pageSize：默认 1/10，pageSize 最大 100

## 三、核心逻辑 → Service 业务逻辑

- **queryRolePage**：单表分页查询（roleName/roleCode 模糊）
- **queryRoleById**：单表查询 + 已分配 permissionIds
- **queryPermissionTree**：查全部 sys_permission（type=目录/页面）→ 用 MenuTreeBuilder 构建全量树（无过滤）
- **saveRole**：校验 roleCode 唯一 → 插入 sys_role
- **updateRole**：查角色存在 → admin 保护拦截 → 更新 roleName/description（roleCode 不可改，避免引用混乱）
- **deleteRole**：查角色存在 → admin 保护拦截 → 事务内删除 sys_role + sys_role_permission + sys_user_role（级联）
- **assignPermissions**：查角色存在 → admin 保护拦截 → 删除该角色全部 role_permission → 逐条插入新关联（空则只删不插）

> **admin 角色保护规则（本方案定义）**：角色编码为 `admin`（内置超级管理员）时，update/delete/assignPermissions 均返回 1006。admin 角色不可编辑、不可删除、不可改权限，默认拥有全部权限。

## 四、关注点 → 权限与事务

- 全部接口加 `@RequiresPermission`：GET → `sys:role:query`；POST → `sys:role:add`；PUT → `sys:role:edit`；DELETE → `sys:role:delete`
- **事务**：deleteRole（3 表级联）、assignPermissions（delete + insert）必须 @Transactional(rollbackFor = Exception.class)，只放 Service 层
- **数据校验兜底**：roleCode 唯一索引兜底 + 代码预校验

### 验收场景（测试用例蓝本，三态）

| # | 场景 | 请求/输入 | 期望 |
|---|------|-----------|------|
| 1 | 分页查询成功 | roleName 模糊筛选 | 200 + total 正确 |
| 2 | 查询详情 | 合法 roleId | 200 + 含 permissionIds |
| 3 | 权限树查询 | 无入参 | 200 + 返回目录/页面层级树 |

| 7 | 编辑成功 | 合法入参 | 200 + 角色信息更新 |
| 8 | 编辑 admin 角色 | roleId=admin | 1006 不允许操作 |
| 9 | 删除成功 | 合法 roleId | 200 + 角色及 role_permission/user_role 级联删除 |
| 10 | 删除 admin 角色 | roleId=admin | 1006 不允许操作 |
| 11 | 分配权限成功 | permissionIds=[1,2,3] | 200 + 关联更新 |
| 12 | 分配权限空集 | permissionIds=[] | 200 + 该角色无权限 |
| 13 | 分配权限给 admin | roleId=admin | 1006 不允许操作 |
| 14 | 角色不存在 | roleId=99999 | 404 角色不存在 |
| 15 | 未登录访问 | 无 token | 401 |
| 16 | 无权限访问 | 登录但无 sys:role:add | 403 |

## 数据模型 DDL（角色侧，与用户侧 sys_user_role 共用）

```sql
-- 角色表
CREATE TABLE `sys_role` (
  `id`          BIGINT       NOT NULL COMMENT '主键ID（雪花）',
  `role_name`   VARCHAR(50)  NOT NULL COMMENT '角色名',
  `role_code`   VARCHAR(50)  NOT NULL COMMENT '角色编码（唯一）',
  `description` VARCHAR(255) NOT NULL DEFAULT '' COMMENT '描述',
  `create_time` DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time` DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  `deleted`     TINYINT      NOT NULL DEFAULT 0 COMMENT '逻辑删除：0-未删 1-已删',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_role_code` (`role_code`),
  KEY `idx_role_name` (`role_name`)
) ENGINE = InnoDB DEFAULT CHARSET = utf8mb4 COMMENT = '角色表';

-- 权限表（预置，无维护接口）
CREATE TABLE `sys_permission` (
  `id`              BIGINT       NOT NULL COMMENT '主键ID（雪花）',
  `permission_name` VARCHAR(50)  NOT NULL COMMENT '权限名',
  `permission_code` VARCHAR(100) NOT NULL COMMENT '权限编码（唯一）',
  `parent_id`       BIGINT       NOT NULL DEFAULT 0 COMMENT '父级ID，0=根',
  `route`           VARCHAR(200) NOT NULL DEFAULT '' COMMENT '路由/URL，目录为空',
  `sort`            INT          NOT NULL DEFAULT 0 COMMENT '排序',
  `type`            TINYINT      NOT NULL COMMENT '类型：1-目录 2-页面',
  `create_time`     DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time`     DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  `deleted`         TINYINT      NOT NULL DEFAULT 0 COMMENT '逻辑删除：0-未删 1-已删',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_permission_code` (`permission_code`),
  KEY `idx_permission_parent` (`parent_id`)
) ENGINE = InnoDB DEFAULT CHARSET = utf8mb4 COMMENT = '权限表';

-- 角色-权限关联表
CREATE TABLE `sys_role_permission` (
  `id`            BIGINT   NOT NULL COMMENT '主键ID（雪花）',
  `role_id`       BIGINT   NOT NULL COMMENT '角色ID',
  `permission_id` BIGINT   NOT NULL COMMENT '权限ID',
  `create_time`   DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time`   DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  `deleted`       TINYINT  NOT NULL DEFAULT 0 COMMENT '逻辑删除：0-未删 1-已删',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_role_permission` (`role_id`, `permission_id`),
  KEY `idx_permission_id` (`permission_id`)
) ENGINE = InnoDB DEFAULT CHARSET = utf8mb4 COMMENT = '角色-权限关联表';
```
